# CleanARs releases

Downloads for CleanARs, the school's waste-sorting app, and for CleanARs Admin, its
desktop admin. This repository holds release files only: no source code, and no
passwords or keys.

| Release | File | What it is |
| --- | --- | --- |
| [`app`](../../releases/tag/app) | `CleanARs.apk` | The newest CleanARs app for Android phones |
| [`admin`](../../releases/tag/admin) | `CleanARs_Admin-update.zip` | The newest CleanARs Admin, for `update.bat` |

Each release keeps one file, replaced by every new version, so these links always give
the newest one:

- App: https://github.com/Oniooons/CleanARs-releases/releases/download/app/CleanARs.apk
- Admin: https://github.com/Oniooons/CleanARs-releases/releases/download/admin/CleanARs_Admin-update.zip

## Updating the app

From version 1.6 on, the app tells students when a new version is out and opens the
download itself. Open the downloaded file and tap **Install**; it installs over the old
version, and accounts and points stay as they are. The first time, Android asks to allow
installs from the browser.

Phones on an older version can open the app link above in their browser instead.

## Updating CleanARs Admin

Close the admin window, then double-click `update.bat` in the CleanARs Admin folder. It
downloads the admin file above, keeps a copy of the current version, and puts that copy
back if anything goes wrong. The school's settings, password and logs are not changed.
