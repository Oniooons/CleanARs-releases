# CleanARs releases

Downloads for CleanARs, the school's waste-sorting app for Android. This repository
holds release files only: no source code, and no passwords or keys.

The [`app`](../../releases/tag/app) release keeps one file, the newest APK, named after
its version (`CleanARs-1.6.apk`). Its name changes with every version, so share the
release page, which always lists the current one:

https://github.com/Oniooons/CleanARs-releases/releases/tag/app

The "Source code" files GitHub adds to every release are copies of this README only.

## Updating the app

From version 1.6 on, the app tells students when a new version is out and opens the
download itself. Open the downloaded file and tap **Install**; it installs over the old
version, and accounts and points stay as they are. The first time, Android asks to allow
installs from the browser.

Phones on an older version can open the release page above in their browser and tap the
APK instead.
